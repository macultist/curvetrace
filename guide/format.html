측정 파일 형식과 장치 통신 규칙

File Format and Serial Protocol
The CSV columns and mode codes the analyzer expects, and the line-based serial protocol between the ESP32-S3 firmware and the live-measurement page.

펌웨어 담당과 분석 담당이 이 형식 하나만 맞추면, 장치가 보낸 줄이 그대로 CSV 가 되고 그 CSV 를 이 사이트에 넣으면 바로 분석됩니다.

1. CSV 열

열 이름뜻예
device소자 번호 (MOSFET 에 붙인 번호)7
rep반복 번호1, 2, 3
temp_c측정 순간의 온도 [°C]45.12
mode스윕 종류 (아래 표)TT
vgsADC 로 잰 실제 게이트−소스 전압 [V]2.1503
vdsADC 로 잰 실제 드레인−소스 전압 [V]2.1498
id_ma드레인 전류 [mA]1.0342

설정값이 아니라 실제로 잰 값을 저장합니다. 열 순서는 달라도 되고, 이름이 비슷하면(Vgs, V_GS, Id [mA], I_D (uA) 등) 자동으로 찾습니다. 전류 단위는 열 이름의 _ma, [mA], (uA) 로 판단하고, 없으면 값 크기로 추정합니다. 제조사·모델·측정 시각 열을 더 넣어도 분석에는 영향이 없습니다.

2. mode 값

mode스윕쓰는 곳
TTV_DS = V_GS 로 함께 올림V_TH(1 mA), g_m
TRV_DS 고정, V_GS 올림전달 특성곡선, g_m
OUTV_GS 단계마다 V_DS 올림출력 특성곡선, R_DS(on)
REF기준 다이오드 (vds=전압, id_ma=전류)온도 블록 검증
LIVE다이얼 조작 중 값실시간 화면 (분석으로 보내면 TR 로 저장)

mode 열이 없으면 V_DS≈V_GS 인지, 어느 전압이 주로 변하는지를 보고 추정합니다. 온도는 설정 온도 단위(기본 5 °C)로 반올림해 묶습니다.

3. 측정 검증 표

kind,ref,meas,stage,dir — kind 는 V(전압, V), I(전류, mA), R(반복 측정). ref 는 DMM 값, meas 는 장치 값, stage 는 before/after, dir 은 up/down 입니다.

4. 장치 → 사이트 (USB 직렬, 115200 baud)

  • 한 줄에 한 측정점, 줄 끝은 \n.
  • 연결 직후 또는 측정 시작 때 헤더 줄 device,rep,temp_c,mode,vgs,vds,id_ma 를 한 번 보냅니다. 헤더가 없으면 vgs,vds,id_ma,temp_c 순서로 읽습니다.
  • # 으로 시작하는 줄은 상태 메시지로 통신 기록에만 보입니다. 예: # 한계 도달: 전력 제한
  • AUTO 스윕이 끝나면 END 한 줄을 보냅니다.
  • LIVE 는 초당 10~20줄이면 충분합니다(ADS1115 3채널 기준).

5. 사이트 → 장치 명령

명령동작
LIVE다이얼 모드 시작
AUTO TTV_DS = V_GS 스윕
AUTO TR 5V_DS = 5 V 고정 전달 스윕
AUTO OUT 3,3.5,4,4.5V_GS 목록마다 출력 스윕
STOP출력을 0 V 로 내리고 정지
SET DEV 7 / SET REP 2다음 측정의 소자·반복 번호
TEMP 45히터 목표 온도

"실시간 측정" 탭의 데모 장치는 이 규칙대로 줄을 보내므로, 펌웨어를 만들기 전에 화면 동작을 미리 확인할 수 있습니다.
