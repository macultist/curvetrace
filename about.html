소개

동국대학교 전자전기공학부 학생 팀의 2026 창의설계 프로젝트, 저비용 인터랙티브 MOSFET 커브 트레이서의 분석 사이트입니다. 직접 만든 측정 장치의 자료를 분석하고, 장치 없이도 MOSFET 동작을 체험할 수 있게 만들었습니다.

왜 만들었나요

MOSFET 은 교과서의 수식과 그래프로 먼저 배우지만, 게이트 전압을 바꿀 때 실제 전류가 어떻게 변하는지는 감을 잡기 어렵습니다. 전자전기·반도체 분야에 관심 있는 학생 39명에게 물었더니 94.9 % 가 전공 선택 전에 직접 체험할 기회가 필요하다고 답했고, 87.2 % 가 다이얼 조작과 실시간 그래프를 쓰는 장치가 이해에 도움이 될 것이라고 답했습니다.

장치와 사이트가 하는 일

  • 장치: ESP32-S3, 16비트 ADC, 12비트 DAC 로 만든 측정기입니다. 다이얼을 돌리면 V_GS 가 바뀌는 LIVE 모드와 자동으로 전압을 바꾸며 측정하는 AUTO 모드가 있습니다. 부품값은 15만 원 이내입니다.
  • 실시간 측정: 장치를 USB 로 연결하면 이 사이트의 그래프 위에서 측정점이 움직입니다.
  • 분석: 같은 모델 2N7000 20~30개의 V_TH·g_m·R_DS(on) 편차, 25·45·65 °C 온도 특성, DMM 과 비교한 측정 정확도를 계산합니다.
  • 초보자 실습: 장치가 없어도 모의 실험과 실습지로 MOSFET 의 세 동작 영역을 체험합니다.

데이터는 어디로 가나요

어디로도 가지 않습니다. 올린 파일과 장치에서 받은 값은 브라우저 메모리에서만 처리되고 서버로 전송되거나 저장되지 않습니다. 자세한 내용은 개인정보처리방침에 적었습니다.

결과의 한계

추출값은 참고용입니다. 자체 제작 장치의 정확도 목표는 전압 2 %, 전류 3 % 이며, 측정 검증 탭에서 실제로 확인합니다. 예제는 모두 합성 데이터이고 실제 측정값이 아닙니다.
